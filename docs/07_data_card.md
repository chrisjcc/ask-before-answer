# Data Card: AskBeforeAnswer Dataset

## Dataset Summary
The AskBeforeAnswer dataset is a synthetic preference dataset built upon the foundational AmbigNQ corpus. It is specifically designed to train language models to identify ambiguous queries, explicitly outline the missing semantic facets using Chain-of-Thought reasoning, and either ask targeted clarifying questions or provide direct answers when appropriate.

## Dataset Structure
The dataset follows a strictly enforced 4-field JSON schema for every response:

1.  **Action:** A binary classification (`Clarify` or `Answer`).
2.  **Reasoning:** A Chain-of-Thought (CoT) trace explaining *why* the question is ambiguous or clear.
3.  **Facets:** A parsed JSON array of the specific semantic attributes missing from the query.
4.  **Response:** The final conversational text (a targeted clarifying question or a direct answer).

### Splits
The dataset is split into contrastive pairs for preference optimization algorithms (DPO/ORPO):
- **Chosen ($y^+$):** High-quality SFT targets synthesized by `qwen2.5-7b-instruct` acting as an expert agent.
- **Rejected ($y^-$):** Plausible but logically flawed responses synthesized using "Prompt-Guided Synthetic Generation" (intentional hallucination of reasoning traces) to create perfectly symmetric hard negatives.

## Dataset Creation
- **Source Data:** AmbigNQ.
- **Generator Model:** `qwen2.5-7b-instruct`.
- **Methodology:** Instead of expensive Model-Grounded Mining, the rejected responses are generated by instructing the model with a negative system prompt to produce structurally perfect but logically flawed reasoning traces.

## Usage
The dataset is processed locally via DVC (`make preprocess`) and tracked via W&B before being pushed to the Hugging Face Hub during the final release process.
